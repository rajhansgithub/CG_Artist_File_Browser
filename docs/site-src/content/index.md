## What the app does

CG Artist File Browser is a Windows file browser for the files a 3D or VFX artist opens all day. You point it at a folder and it shows the files as pictures: 3D models turn in a viewer, HDR and EXR maps open as a 360° sky with exposure controls, textures can be compared side by side, and video, audio, PDF and render textures (`.tx`, `.tex`) open right where you are. Nothing is uploaded anywhere.

## Start in a minute

1. Open a folder from the sidebar, or press `Ctrl` + `L` and type a path such as `D:\Projects\Shot_010`.
2. Click a file once to select it, press `Space` to preview it in a floating window, or double-click to open it fully.
3. Press `?` at any time to see every keyboard shortcut.
4. Press `/` anywhere in this guide to search it.

## Which level should I read?

- **Quick start** is for everyday use: what a screen does, how to do a common task, and the keys you need most.
- **Deep dive** has one page per feature, with every option, the file formats it understands and what to do when something looks wrong.
- Each page has a link to the other level when there is one, and the **Quick start / Deep dive** switch at the top moves between them.

## About the pictures

The screenshots and animated clips in this guide were captured from a browser build of the app with sample files, not from the installed Windows app. They show the same screens and controls. Their file names are stable, so a real screenshot can replace one by copying a file over it. See the [FAQ](@shared/faq) for more.
