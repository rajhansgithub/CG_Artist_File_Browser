## The main screen

![The folder view with thumbnails, the sidebar on the left and the path bar on top](media:grid-models.webp "A folder of models. The sidebar lists drives, network locations, recent and pinned folders.")

- **Sidebar, left.** Drives and network shares, recent folders, pinned folders, and the assets you starred. The box at the bottom counts the files in the current folder.
- **Path bar, top.** Where you are, with back, forward and up buttons. Click the empty part of the path, or press `Ctrl` + `L`, to type a path.
- **Filter box, top right.** Type to narrow the folder to matching names. The type buttons next to it show only 3D, HDR, images, video, audio, PDF or Markdown files.
- **Views.** Thumbnails by default. The list icon switches to a details list with name, date, type and size. Your choice is remembered.

![The same folder in the details list](media:details-view.webp "Details view: click a column header to sort")

## Preview without opening: Quick Look

Select a file and press `Space`. A small window opens over the folder and shows the file in its own viewer. Press the arrow keys to move through the folder; the window follows. `Space` or `Esc` closes it, `Enter` opens the full viewer.

![Quick Look over a folder of textures](media:quick-look.webp "Quick Look shows a texture without leaving the folder")

![Moving through a folder with the arrow keys while Quick Look stays open](media:quick-look.gif "Arrow keys move the selection, and the preview follows")

## Select several files

`Click` picks one file. `Ctrl` + `Click` adds or removes one, `Shift` + `Click` selects a range, and dragging on empty space draws a box. `Ctrl` + `A` selects everything. The status bar at the bottom says how many are selected and their total size.

![Ctrl and Shift clicks building a selection](media:multi-select.gif "Ctrl + Click and Shift + Click build up a selection")

## Right-click for actions

Right-click a file or folder for its menu: open, reveal in Explorer, copy the path, rename, delete, send to an app, add it to favourites, label it, convert images, or find duplicates in a folder.

![The right-click menu on a texture](media:context-menu.webp "The menu changes with the file type. Send to shows the apps you added in Settings.")

## Compare two files

Each card has an **A** and a **B** button. Pick two files, then press **Compare** in the bar at the bottom. Drag the divider to wipe between them, or use the modes in the top bar.

![Two renders in the compare bar, with the Compare button](media:compare-dock.webp "Pick slot A and slot B, then press Compare")

![Dragging the divider in a comparison](media:compare-wipe.gif "The wipe divider shows how the two versions differ")
